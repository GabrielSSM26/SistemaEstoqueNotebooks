# Sistema de Estoque de Notebooks

## Sobre o projeto

Este projeto desenvolvido em C++ e tem como objetivo
gerenciar o estoque de notebooks, permitindo cadastrar,
consultar, listar e excluir produtos.

Os dados são armazenados em um arquivo binário, e o sistema
também permite exportar as informações para um arquivo TXT.

## Funcionalidades

1. Cadastrar notebooks.
2. Consultar notebooks pelo código.
3. Listar notebooks cadastrados.
4. Excluir notebooks utilizando exclusão lógica.
5. Exportar o estoque para um arquivo TXT.
6. Contabilizar notebooks ativos e registros armazenados.

## Tecnologias utilizadas

- Linguagem C++
- Arquivos binários
- Arquivos de texto (TXT)
- Structs e funções

## Arquivos do projeto

- `main.cpp`: código-fonte do sistema.
- `estoque.dat`: arquivo binário que armazena os registros.
- `estoque.txt`: arquivo gerado pela exportação do estoque.

## Como executar

1. Compile o arquivo `main.cpp` utilizando um compilador C++.
2. Execute o programa gerado.
3. Utilize o menu para acessar as funcionalidades.
